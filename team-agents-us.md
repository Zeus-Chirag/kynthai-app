## Communication Protocol

- All blockers: escalate to Release Master via team task system
- Legal changes: Legal Counsel approval required before merge
- Security findings: Security Lead triage, P0 immediately to Release Master
- Test failures: QA Eng triage; if infrastructure-related, escalate to DevOps
