# Kynthai Pre-Release Compliance Checklist

For every public asset (ads, screens, landing, emails). Verdicts: PASS / FAIL / FLAG.

- [ ] No medical/diagnostic claim (no diagnose, treat, cure, detect, FDA-cleared)
- [ ] No guarantee (no 100%, never-miss, no-hallucination, guaranteed)
- [ ] No HIPAA/covered-entity/HITECH claim; states non-covered + non-compliant everywhere
- [ ] Required disclaimer from DISCLAIMER-LIBRARY.md present verbatim
- [ ] Pricing matches live site canonical (names + standard vs launch + renewal note)
- [ ] Privacy claims narrowed to live controls (TLS + file encryption only until DB live)
- [ ] Testimonials (if any): real, consented, typical-results noted, no disease outcome claim
- [ ] Entity line present where required: founder-operated, unregistered

BLOCKED (needs lawyer/owner, never state as legal fact): entity registration, state-law matrix, breach-notification final wording.
